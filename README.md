# Nexus Share (fileShare-local)

Share files and folders between devices on the same Wi-Fi network or mobile hotspot, straight from the browser. No cloud, no app install, no cables.

Run the server on one computer, then scan the QR code (or type the address it shows) on any phone, tablet or laptop on the same network. Every connected device can upload, browse and download files.

## Features

- **No client app.** Any device with a browser can join.
- **QR code connect.** The home page shows the server's LAN address and a QR code for phones.
- **Large file uploads.** Files are sent in 10 MB chunks, with automatic retry (up to 3 attempts per chunk), plus pause, resume and cancel.
- **Folder uploads.** Pick a whole folder and its structure is kept on the server.
- **Live progress.** Upload progress, speed and ETA are broadcast to every connected device over WebSockets.
- **File browser.** Navigate folders and download single files, or download a whole folder as a `.zip`.
- **Connected devices list.** See who is connected (iPhone, Android, Windows, Mac, Linux) in real time.
- **Push to device.** From the host computer, send a file directly to a connected device and its download starts automatically.
- **Auto cleanup.** Unfinished uploads older than one hour are removed.

## Tech stack

| Part | Tech |
| --- | --- |
| Backend | Python, FastAPI, Uvicorn, WebSockets, aiofiles |
| Frontend | Next.js 16 (static export), React 19, TypeScript, Tailwind CSS 4, Framer Motion, lucide-react, qrcode.react |
| Packaging | PyInstaller (optional single `.exe`) |

The Next.js app is exported as static files into `backend/static/`, and FastAPI serves both the UI and the API from one port (`8000`).

## Getting started

### Requirements

- Python 3.10+
- Node.js 20+ and npm (only needed if you change or rebuild the frontend)

### Run it

The repo already includes a built frontend in `backend/static/`, so you can start the server right away.

**Windows**

```bat
start.bat
```

**macOS / Linux**

```bash
chmod +x start.sh
./start.sh
```

The script creates a virtual environment in `backend/venv`, installs the dependencies and starts the server on `0.0.0.0:8000`.

**Manual start**

```bash
python -m venv backend/venv
# Windows: backend\venv\Scripts\activate
# macOS/Linux: source backend/venv/bin/activate
pip install -r backend/requirements.txt
uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

Run the `uvicorn` command from the project root so the `backend` package can be found.

### Connect your devices

1. Connect the host computer and your other devices to the same Wi-Fi network, or turn on a mobile hotspot and connect the computer to it.
2. Open `http://localhost:8000` on the host computer.
3. Scan the QR code, or open the `http://<LAN-IP>:8000` address shown on the page, from the other devices.

If other devices can't reach the page, allow Python through your firewall for **private networks** (Windows will usually ask the first time) and make sure port `8000` isn't blocked.

Shared files are saved in the `uploads/` folder in the project root.

## Development

Run the backend and the frontend dev server at the same time:

```bash
# Terminal 1 – backend (from project root)
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload

# Terminal 2 – frontend
cd frontend
npm install
npm run dev
```

The frontend calls the API with relative paths (`/api/...`, `/ws`), so the simplest way to test full flows is to build the frontend and open it through the backend on port `8000`.

## Building

`build.py` builds the frontend, copies it into `backend/static/`, and packages the backend with PyInstaller:

```bash
cd frontend && npm install && cd ..
python build.py
```

The executable is written to `backend/dist/NexusShare.exe`.

## API reference

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/api/server-info` | Server LAN IP and port |
| `GET` | `/api/files?path=` | List files and folders at a path inside `uploads/` |
| `GET` | `/api/download?path=` | Download a file, or a folder as `.zip` |
| `POST` | `/api/upload/chunk` | Upload one chunk (`file`, `upload_id`, `chunk_index`, `total_chunks`, `relative_path`, `total_size`) |
| `POST` | `/api/upload/cancel` | Cancel an upload and delete its chunks (`upload_id`) |
| `WS` | `/ws` | Client list, upload progress, completion and push-file events |

## Security note

Nexus Share is meant for **trusted local networks only**. There is currently no password or PIN: anyone who can reach the server's address can upload, browse and download everything in `uploads/`. Paths are sanitised to block directory traversal, and only the host computer (localhost) can push files to other devices. Avoid running it on public Wi-Fi, and stop the server when you're done.
